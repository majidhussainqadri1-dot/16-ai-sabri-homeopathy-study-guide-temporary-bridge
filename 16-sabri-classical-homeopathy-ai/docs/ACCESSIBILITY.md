# Accessibility and Inclusive Design

Implemented source contracts: semantic landmarks/labels, live status, predictable keyboard order, 44px targets, visible focus, RTL logical CSS and mirrored direction icon, reduced motion, forced colors, reduced-data/low-bandwidth behavior, responsive layouts and a public accessibility statement.

Required staging evidence: keyboard-only journeys, screen-reader testing, 200%/400% zoom, Urdu/Arabic RTL, high contrast, reduced motion/data, representative low-end mobile and browser/device matrix. No repository-only claim substitutes for human assistive-technology evidence.
