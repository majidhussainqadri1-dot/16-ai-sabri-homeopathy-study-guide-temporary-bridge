A branded, temporary access bridge for AI Sabri Homeopathy Study Guide while Native Sabri AI is developed.

== Description ==

This modular plugin creates a public AI Study Guide page, connects the main AI navigation item, and adds a geometric floating access button to the Home Page.

The current approved Custom GPT URL is:
https://chatgpt.com/g/g-68baba42df9081918a2e3b53a4b76df8-ai-sabri-homeopathy-study-guide

Important: Custom GPT pages are hosted by ChatGPT and are not guaranteed to work inside an iframe. Authentication, browser security, or ChatGPT security policies may block embedded access. Therefore, this plugin always shows a secure external fallback link. The user is never left with a dead end.

This version does not use an API key and does not contain Native Sabri AI. The provider layer keeps that later replacement modular.

== Installation ==

1. Keep the Sabri Platform Foundation plugin (File 01) active.
2. Upload the ZIP through Plugins > Add New > Upload Plugin.
3. Activate the plugin.
4. Clear the Hostinger and browser caches.
5. Open Settings > AI Study Guide to review the approved URL and display options.

The plugin creates or updates the page:
AI Sabri Homeopathy Study Guide

Default path:
/ai-sabri-homeopathy-study-guide/

The floating button appears only on the WordPress front page or the Home Page registered by the Sabri Platform Foundation.

== Safety and Privacy ==

The Study Guide is for education only. It does not diagnose, prescribe, recommend potency or dosage, guarantee outcomes, or replace qualified medical or emergency care.

Users are warned not to enter names, contact details, addresses, medical records, or other identifiable patient information. A suggested privacy-policy disclosure is registered with WordPress.

The AI page uses noindex and noarchive instructions because it is a temporary third-party access bridge.
